# دوستیابی وصال

**وصال** یک پروژه برای ایجاد فضایی ساده، امن و محترمانه جهت آشنایی و ارتباط واقعی میان بزرگسالان است.

> اصل بنیادین: ثبت‌نام، مشاهده و جست‌وجوی کاربران و پیام‌دادن باید رایگان بماند؛ هیچ قابلیت ضروری ارتباطی پشت اشتراک یا پرداخت قرار نمی‌گیرد.

## هدف نسخهٔ نخست

- مخاطبان: افراد ۱۸ سال به بالا
- محدودهٔ شروع: ایران
- زبان رابط کاربری: فارسی و راست‌به‌چپ
- بستر آغازین: وب‌اپ سازگار با تلفن همراه؛ امکان توسعهٔ نسخهٔ اندروید در مرحلهٔ بعد
- جست‌وجوی افراد بر اساس شهر و فیلترهای پایه
- پروفایل کاربری با اطلاعاتی که خود فرد آگاهانه منتشر می‌کند
- پیام‌رسانی مستقیم و رایگان میان کاربران
- امکان گزارش حساب یا محتوا و مسدودکردن کاربران

## اصول محصول

1. **رایگان‌بودن ارتباط:** برای ثبت‌نام، دیدن پروفایل‌ها، جست‌وجو و ارسال پیام هزینه یا اشتراک اجباری دریافت نمی‌شود.
2. **حریم خصوصی:** اطلاعات شخصی کاربران فروخته نمی‌شود و فقط داده‌های ضروری برای ارائهٔ سرویس نگهداری می‌شوند.
3. **امنیت و احترام:** گزارش تخلف، مسدودسازی، رسیدگی به شکایت و قواعد روشن استفاده بخشی از طراحی محصول‌اند.
4. **شفافیت:** پیش از انتشار عمومی، سیاست حریم خصوصی، شرایط استفاده و شیوهٔ نگهداری و حذف داده‌ها باید روشن باشند.
5. **طراحی مسئولانه:** سن کاربران باید در فرایند ثبت‌نام بررسی شود؛ صرفاً واردکردن یک تاریخ تولد، به‌تنهایی اثبات قطعی سن محسوب نمی‌شود.

## وضعیت توسعه

مخزن در مرحلهٔ ساخت زیرساخت است. رابط نمایشی و فرم احراز هویت کدنویسی شده‌اند، اما تا زمان پیکربندی و آزمایش Supabase، هیچ ثبت‌نام یا پیام‌رسانی واقعی فعال نیست.

## فناوری

- رابط: HTML/CSS/JavaScript
- احراز هویت و پایگاه داده: Supabase Auth و PostgreSQL
- میزبانی وب پیشنهادی: GitHub Pages برای فایل‌های ایستا؛ دسترس‌پذیری و محل میزبانی سرویس‌های موردنیاز داخل ایران باید پیش از عرضه بررسی شود.

## ثبت‌نام و ورود

- نسخهٔ فعلی از ایمیل و گذرواژه استفاده می‌کند؛ OTP شماره موبایل ایران هنوز پیاده‌سازی نشده است.
- نشانی پروژه و کلید عمومی (publishable/anon key) فقط در `supabase-config.js` قرار می‌گیرند.
- کلید محرمانهٔ سرور (service role/secret key) هرگز نباید در مرورگر، فایل‌های عمومی یا مخزن Git قرار گیرد.
- مهاجرت‌ها باید به ترتیب `0001_initial_schema.sql`، `0002_signup_profile_trigger.sql`، `0003_private_block_helper.sql` و `0004_lock_birth_date.sql` اجرا شوند.
- صفحه‌های [قوانین استفاده](rules.html) و [حریم خصوصی](privacy.html) پیش‌نویس‌اند و پیش از عرضه عمومی نیازمند بازبینی حقوقی و تکمیل فرایندهای اجرایی هستند.

## مشارکت و بازخورد

در این مرحله تمرکز بر ساخت تدریجی یک محصول قابل استفاده، امن و پایدار است. پیشنهادها و گزارش اشکال‌ها باید با احترام به حریم خصوصی افراد مطرح شوند.
