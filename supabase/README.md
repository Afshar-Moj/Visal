# وصال — راه‌اندازی پایگاه داده

این پوشه شامل طرح اولیهٔ پایگاه دادهٔ وصال برای PostgreSQL و Supabase است.

## راه‌اندازی

1. یک پروژهٔ Supabase ایجاد کنید.
2. از بخش SQL Editor، فایل `migrations/0001_initial_schema.sql` را اجرا کنید.
3. در Authentication، ورود با ایمیل را فعال کنید و تنظیمات تأیید ایمیل و محدودیت‌های امنیتی را پیش از انتشار بررسی کنید.
4. نشانی پروژه و کلید عمومی (publishable/anon key) را فقط در تنظیمات محیطی رابط کاربری قرار دهید.
5. کلید محرمانهٔ سرور (service role/secret key) هرگز نباید در مرورگر، فایل‌های عمومی یا مخزن Git قرار گیرد.

## جداول

- `profiles`: اطلاعات قابل نمایش پروفایل؛ تاریخ تولد در این جدول نیست.
- `private_user_data`: تاریخ تولد خصوصی؛ فقط خود کاربر می‌تواند آن را بخواند یا ویرایش کند و پایگاه داده حداقل سن ۱۸ سال را کنترل می‌کند.
- `user_blocks`: مسدودسازی دوطرفه در کشف پروفایل و پیام‌رسانی.
- `conversations` و `messages`: گفت‌وگو و پیام خصوصی میان دو عضو.
- `user_reports`: ثبت گزارش تخلف.

## ملاحظات امنیتی

- سیاست‌های امنیت در سطح ردیف (RLS) برای همهٔ جدول‌ها فعال شده‌اند.
- اطلاعات تاریخ تولد از جدول پروفایل عمومی جدا نگه داشته شده است.
- کاربر فقط می‌تواند پروفایل و دادهٔ خصوصی خودش را ایجاد یا ویرایش کند.
- وضعیت رسیدگی به گزارش‌ها عمداً از دسترس مستقیم کاربران خارج است؛ پنل مدیریت باید از مسیر امن سمت سرور ساخته شود.
- این طرح، زیرساخت اولیه است و پیش از استفادهٔ واقعی باید با آزمون‌های امنیتی، محدودسازی نرخ درخواست، کنترل هرزنامه، فرایند رسیدگی به گزارش‌ها و الزامات قانونی محل عرضه تکمیل شود.

## نکتهٔ مهم دربارهٔ سن

کنترل تاریخ تولد در پایگاه داده مانع ثبت تاریخ تولدِ نشان‌دهندهٔ سن کمتر از ۱۸ سال می‌شود؛ اما به‌تنهایی هویت یا سن واقعی فرد را اثبات نمی‌کند. هر روش تأیید سن قوی‌تر باید با حداقل‌سازی داده و بررسی حقوقی طراحی شود.
